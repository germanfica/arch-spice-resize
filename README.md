# arch-spice-resize

Minimal automatic display resizing for Arch Linux with i3 and QEMU/KVM SPICE.

Designed to complement [arch-i3](https://github.com/germanfica/arch-i3) and [arch-spice](https://github.com/germanfica/arch-spice).

## Installation

```bash
curl -fsSL https://raw.githubusercontent.com/germanfica/arch-spice-resize/main/install.sh | bash
```
